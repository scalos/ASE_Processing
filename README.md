# ASE_Code

Asymmetric spin echo (ASE) processing: preprocessing of raw DICOMs and voxelwise / ROI estimation of R2′, venous CBV, OEF and R2. Includes optional through-slice (z-shim) correction and a voxel quality mask.

See **[docs/](docs/README.md)** for:

- [settings](docs/settings.md)
- [outputs](docs/outputs.md)
- [method decisions](docs/decisions.md)
